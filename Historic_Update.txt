####################### Version 25.08 #######################

[UPDATE]

####################### Version 20.03 #######################
01/2022
[UPDATE]
1 - Introducing two New Excel Sheet "S_Conc. & Err. "
This two new sheet show the concentration in ppm or in pourcentage with the calculated error on the adjacent cell
	- Special Sheet  «S_Conc. & Err. 100% » Conc. 100% looping concentration expressed in % follow by its error expressed in %
	- Special Sheet  «S_Conc. & Err. ppm » conc. 100% looping, concentration expressed in ppm follow by its error expressed in %
2 - Element tagged 'Y' Determine the best value only with FIT ERROR and PIVOT_ERROR
	After contacting Iain Campbell it seems that the Stat Error output is a old and none adapted error to take in concideration.
	It was a mistake to add the 2 error Fit and Stat. They do not represent two different error but to way of processing the error into GUPIX (See section 13C Gupix manual)
	- The Sheet "Stat_Error" is not anymore created in the excel file
	- The "Stat_Error" value is not included into the algorythm of best value determination
		--> Matrix Error(%) = FIT_Error
		--> Pivot Error(%) =  sqrt(Pivot_Error_Mat^2 + FIT_Error_Trc^2), only for the Pivot element present in both spectra
		--> Trace Error(%) = sqrt(Pivot_Error^2 + FIT_Error ^2) 

3 - Best element with '?' is not anymore selected with the lowest LOD but with the lowest Error
4 - Best element with 'N' is selected with the lowest LOD
5 - Icon 'T' added

2- Element 'Y' Selection of the best value with the lowest error calculated on the base of the quadratic sum of Fit and stat error as :
	--> Matrix Error(%) = sqrt(STAT_Error^2 + FIT_Error ^2)
	--> Pivot Error(%) = sqrt(STAT_Error^2 + FIT_Error ^2) only for the Pivot element present in both spectra
	--> Trace Error(%) = sqrt(Pivot_Error^2 + STAT_Error^2 + FIT_Error ^2) 

3 - Best element with '?' is selected with the lowest LOD 
4 - Best element with 'N' is selected with the lowest LOD
